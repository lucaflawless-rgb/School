## Description of the project


This is a keyboard and drums made by luca fennell lawless and sam o donnell. We have option in the UI where you can record, save and play music. We choose a keyboard and drums as we thought they would be interesting to make using midi player. We mapped the diffent keys and drum elements to keys on our keyboard.

## Instruction

You can play the drums or keys by clicking on them with your mouse. The drum elements and keys have key binds to different keys on the keyboard as well. You can play a tune and click record and save the recording to play it at a later date.

## How it works

A drum pad is a grid of buttons, each mapped to a keyboard key and mouse click, that plays a specific drum sound when triggered. Visual feedback shows which pad is active.

A keyboard is a row of piano keys mapped to keyboard shortcuts and mouse input, each playing a specific musical note. Together they form a playable instrument with record, save, and playback functionality.
